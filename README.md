One line from a hardware wallet refusing to sign a 3 AM transaction —
not because its battery died or its firmware needs an update, but
because it still carries the last 3 AM idea it ever signed, and that
one is worth four cents now. The wallet has a grudge, a memory, and a
curfew. Ask again at noon.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, one line, no
trailing newline) and verifies the file round-trips byte-identical.
